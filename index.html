Database System

02. Sarawak Heritage Online Auction (SHAA)

An online auction platform built to digitize the trading of Sarawakian heritage items. The core of the system is a relational database designed via Crow's Foot ERD and strictly normalized to 3NF to prevent data anomalies. Key functionalities include a secure payment gateway, automated delivery tracking, and real-time bidding records.

Tech Stack: HTML, PHP, MySQL (phpMyAdmin), XAMPP

UI/UX Design

03. KUTS ART Mobile App

A mobile application prototype built to enhance the public transport experience for the Kuching ART System. Built in Figma, the design features an interactive station routing map, a smart search system, and an inclusive interface for visually impaired users. The user experience was finalized after conducting System Usability Scale (SUS) testing to ensure a smooth ticket booking flow.

Tech Stack: Figma, UI/UX Design, Prototyping, Usability Testing
